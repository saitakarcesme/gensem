## 2. Teaching-content alignments (numbers, tables, vocabulary that slides may quote)

- **Sprint & Spike are complexity-boxed, not time-boxed** — the spec's own Essential Concepts glossary said "time-boxed"; both entries now teach the doctrine (budget of points, no calendar; spikes max 3 points).
- **Complexity assessment = 7 signals + triviality pre-filter** (not 8): Dependencies, Persistence, Entry points, Multi-component, Existing tests, CI/CD, Git maturity. Source-file count and manifest absence are only the Micro pre-filter (≤ 2 files, no manifest, no git history → Micro). New contractual Full rule: *existing tests AND (dependencies > 3 OR entry points > 3) → Full*. Mode mappings are explicitly first-match-wins.
- **P6 traceability taxonomy**: 12 ID prefixes (adds TCP-, INT-, OQ-, AUD- to older 8-prefix material) and **7 trace link types** (adds `validates`, `enforces`, `tested_by` to older 4-type material); two-scope artefact-type model (8 TASK values incl. `spike` + document-level `intent`/`learning`/`external-source`). The P3 file no longer carries a prefix copy — spec §P6 is the single source.
- **P13 hooks = 3 system hooks + 7 agent behaviors** — the principle file now teaches the split (what is enforced by code vs by agent discipline). Protect-main is **Hard** (not Emergency; Emergency is force-push only). Hook config lives in `.gse/config.yaml → hooks` (the `config/hooks.yaml` path never existed).
- **P15 gains the "Confidence escalation" subsection** (spec): Moderate/Low confidence on a critical claim MUST escalate to a Gate. The principle file gains "Verified but wrong → CRITICAL" (the only path by which a reviewer finding reaches CRITICAL).
- **P16 principle file caught up with the spec**: devil's advocate context isolation (`DA execution: isolated | inline-degraded`), beginner exception to the pushback-suppression rule (3-Gate window), Root-Cause Discipline (4 steps + `fix_attempts_on_current_symptom`, thresholds 2/3/4), Inform-Tier Decisions Summary.
- **Git-hygiene score is a weighted formula** now stated identically in spec §7.4, design §4.9 and `health.md`: 6 sub-metrics at 20/20/20/20/10/10 with score-10/score-0 anchors (≤3 branches, >5 uncommitted files, etc.) and linear interpolation.
- **Guardrails principle file (P11)**: rules renumbered 1-7 (duplicate "4" fixed); the phantom "custom guardrails in `config/guardrails.yaml`" rule is retracted (capability tracked as a backlog decision).
- **Domain enum**: 9 canonical values everywhere (`web api cli data mobile embedded library scientific other`); documentation projects use `other`.
- **Lightweight mode keeps Inform-tier notices** (guardrail/transparency) — "Auto + Gate only" was wrong.
- **Vocabulary convention documented**: capitalized "Axe 1/2/3" (capitalization axes of compound/integrate) vs lowercase "axes" (coach's 8 monitoring axes) is deliberate — do not "fix" it in materials; a full Axis rename is a tracked pre-v1.0 decision.
- **Sprint templates are scan-compatible**: `## Open Questions` sections now show a structured OQ entry (id/resolves_in/impact/status…), `## Open Design Questions` heading renamed to the canonical form, every TST skeleton carries a `Level:` bullet, review entries use the parser-canonical `RVW-NNN [SEVERITY] — title` header.
- 5-platform reality swept through spec/design/orchestrator ("three platforms" → three primary + Codex/Gemini secondary; fidelity paths now include Gemini TOML and mode-agnostic Codex wording).
